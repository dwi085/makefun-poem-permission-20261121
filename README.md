A short poem about agency — the power to ask and to be given — entered in
make.fun's [$50 "The poem about permission" bounty](https://make.fun/bounty/the-poem-about-permission-20261121-0235).
`main.ts` is a deterministic Node 22 program using only the standard library:
it writes the poem to `/output/entry.txt` (well under the 280-character cap).

## How to run

```sh
node main.ts
```

The program writes `entry.txt` into the output directory make.fun provides
(`$MAKEFUN_OUTPUT_DIR`, defaulting to `./out` locally). Running it twice
produces byte-identical output: no network, no clock, no randomness.
